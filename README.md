# Tic-Tac-Toe AI

A simple Tic-Tac-Toe game with a graphical interface and an AI opponent powered by the Minimax algorithm.

## Features

- Play as **X** or **O**
- Interactive GUI built with `pygame`
- AI chooses optimal moves using Minimax
- Detects wins, losses, and ties
- Option to restart the game after it ends

## Requirements

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python runner.py
```

## Project Structure

- `runner.py` — launches the graphical game interface
- `tictactoe.py` — contains the game logic and Minimax AI
- `requirements.txt` — lists required Python dependencies
